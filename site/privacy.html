개인정보처리방침

시행일 2026년 8월 15일 · 게시자 Aura Media · 문의 지원 페이지

Aura Media Downloader는 호환 가능한 미디어를 감지하고 사용자가 다운로드 권한을 가진 미디어를 저장하도록 돕는 Chrome 확장 프로그램입니다. 이 방침은 Chrome 웹 스토어 일반판에 적용됩니다.

처리하는 정보

확장 프로그램은 미디어 감지 및 사용자가 요청한 다운로드를 수행하기 위해 현재 페이지의 URL과 제목, 호환 가능한 미디어 URL과 형식, 페이지 리퍼러와 언어 설정, 후보 메타데이터 및 다운로드 작업 상태를 일시적으로 처리합니다. 미디어 감지를 위해 방문 중인 페이지의 요청 URL을 일시적으로 관찰하며, 탐색 기록을 저장하거나 보관하지 않습니다. 인증, 쿠키 및 API 키 헤더는 보관하거나 재사용하지 않고 폐기합니다. 다운로드 세션 상태는 기능 수행을 위해 기기에 저장될 수 있습니다.

Pro 라이선스를 활성화하면 사용자가 입력한 라이선스 키와 임의로 생성된 기기 식별자(UUID)를 로컬에 저장하고, 유효성 확인과 기기 제한 적용을 위해 Aura 라이선스 서버로 전송합니다. Aura 계정, 비밀번호, 쿠키, 결제 정보, 정밀 위치, 건강 정보 또는 광고 식별자는 요구하지 않습니다. 개인정보를 판매하거나 탐색 활동을 광고에 사용하지 않습니다.

정보가 전달되는 위치

미디어 요청은 사용자가 선택한 원본 사이트 또는 미디어 호스트로 전송됩니다. 미디어나 탐색 데이터를 Aura 서버로 업로드하지 않습니다. 다운로드는 사용자가 선택한 로컬 폴더에 기록하며, 오프스크린 워커로 직접 저장할 수 없는 경우에는 단일 미디어 파일을 브라우저 기본 다운로드 기능으로 저장할 수 있습니다.

보관과 삭제

후보 데이터, 요청 메타데이터 및 다운로드 상태는 기능에 필요한 확장 세션 또는 로컬 저장소에 보관됩니다. 사용자는 설정에서 다운로드 폴더를 지우거나 확장 프로그램을 제거할 수 있습니다. 이미 저장한 파일은 사용자의 관리 아래 남으며 확장 제거 시 자동 삭제되지 않습니다.

제3자 사이트와 이용 권한

본 도구는 제3자 사이트의 이용약관을 변경하지 않습니다. 사용자는 해당 사이트의 약관, 저작권법 및 라이선스를 준수해야 합니다. DRM, 로그인 제한, 유료벽, 비공개 영상 제어 또는 기타 접근 통제를 우회하지 않습니다.

보안과 변경

게시자는 확장 프로그램의 로컬 저장 처리에 합리적인 보호 조치를 적용합니다. 중요한 변경은 새 시행일과 함께 이 페이지에 게시합니다.

Chrome 웹 스토어 데이터 정책 준수

본 확장 프로그램은 Chrome 웹 스토어 사용자 데이터 정책(Chrome Web Store User Data Policy)을 준수합니다. Google API로부터 받은 정보의 사용은 제한적 사용(Limited Use) 요건을 포함한 해당 정책을 따릅니다. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
