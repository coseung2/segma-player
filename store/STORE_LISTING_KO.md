## 이름

Aura Media Downloader

## 짧은 설명

호환 가능한 미디어를 감지하고 권한 있는 다운로드를 로컬에 저장합니다.

## 상세 설명

Aura Media Downloader는 사용자가 이용·다운로드 권한을 가진 웹페이지에서 호환 가능한 영상·오디오 리소스를 찾고 로컬에 저장하도록 돕는 단일 목적 도구입니다.

주요 기능:

- 현재 페이지의 호환 가능한 직접 영상과 스트리밍 미디어 감지
- 페이지 제목, 미디어 종류, 가려진 리소스 주소를 보여 주는 텍스트 기반 후보 목록
- 호환 가능한 미디어 주소 또는 플레이어 페이지의 직접 입력
- 확장 팝업에서 대기·진행·완료·실패 다운로드 상태 확인
- 미디어를 Aura 서버로 업로드하지 않고 로컬에 저장

무료 버전은 미디어 작업 1개 동시 실행과 다운로드 1건당 1GiB 제한을 제공합니다. Pro는 미디어 작업 3개 동시 실행, 인위적인 용량 제한 없음, 지원 미디어의 최고 화질 선택을 제공합니다.

본 확장 프로그램은 저작권자이거나 다운로드 권한을 가진 미디어에만 사용하십시오. DRM, 로그인 제한, 유료벽, 비공개 영상 제한 또는 접근 통제를 우회하지 않습니다. 페이지·미디어 형식·브라우저·컴패니언 도구에 따라 호환성이 달라지며 모든 사이트와 형식의 동작을 보장하지 않습니다.
